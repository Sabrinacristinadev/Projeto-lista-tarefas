# Gerenciador de Tarefas

Este é um projeto simples de **Gerenciador de Tarefas** desenvolvido utilizando **HTML**, **CSS** e **JavaScript**. Ele oferece uma interface simples e intuitiva para o usuário adicionar, listar, marcar como concluídas e excluir tarefas, ajudando na organização do dia a dia.

## Funcionalidades

- **Adicionar tarefas**: O usuário pode criar novas tarefas a serem realizadas.
- **Excluir tarefas**: As tarefas podem ser removidas da lista.
- **Marcar como concluída**: É possível marcar as tarefas como concluídas, com um efeito visual.
- **Armazenamento persistente**: As tarefas são salvas no `localStorage`, garantindo que as informações não sejam perdidas ao recarregar a página ou fechar o navegador.

## Tecnologias Utilizadas

- **HTML5**: Usado para estruturar o conteúdo da página.
- **CSS3**: Responsável pelo estilo e layout, deixando a interface mais agradável e funcional.
- **JavaScript**: Usado para implementar a lógica de interação, como adicionar, excluir e marcar as tarefas.
